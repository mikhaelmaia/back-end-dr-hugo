# Política de Privacidade - Médicos

## Responsabilidades como Profissional da Saúde

Como **médico cadastrado** em nossa plataforma, você tem responsabilidades específicas no tratamento de dados pessoais de pacientes.

## Dados dos Pacientes

- Você tem acesso aos dados médicos dos seus pacientes
- **Sigilo médico**: É obrigatório manter confidencialidade total
- Apenas dados necessários para atendimento são compartilhados
- Logs de acesso são mantidos para auditoria

## Seus Dados Profissionais

- Dados do CFM são verificados automaticamente
- Especialidades e informações profissionais são públicas
- Você controla a disponibilidade para novos pacientes

## Como Protegemos os Dados

1. **Criptografia end-to-end** para documentos médicos
2. **Controle de acesso** baseado em relação médico-paciente
3. **Auditoria completa** de todas as ações na plataforma
4. **Backup seguro** com retenção conforme normas do CFM

## Suas Responsabilidades

- ⚖️ Cumprir as normas do CFM sobre prontuários digitais
- 📋 Manter dados dos pacientes atualizados e precisos
- 🔒 Não compartilhar credenciais de acesso
- 🚫 Usar dados apenas para fins médicos legítimos

_Esta política foi adaptada especialmente para médicos da plataforma Dr. Hugo._
